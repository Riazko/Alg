# Домашняя работа 1 — выбранные задачи на Python

В каталоге лежат отдельные решения на Python 3 для задач №6, 9, 17, 18, 19 и 21, а также подробный разбор алгоритмов и кода.

Запуск каждого решения из командной строки:

```text
python task06_polynomial.py < input.txt
```

Имя файла меняется в соответствии с номером задачи. Остальные решения запускаются так же.

Файлы:

- `task06_polynomial.py` — вычисление полинома схемой Горнера по модулю;
- `task09_trees.py` — подсчёт наборов деревьев, образующих арифметическую прогрессию;
- `task17_guards.py` — проверка двойного покрытия временных отрезков;
- `task18_attraction.py` — восстановление таблицы обменами строк и столбцов;
- `task19_deque.py` — дек фиксированной вместимости на кольцевом массиве;
- `task21_heapsort.py` — пирамидальная сортировка участников;
- `Разбор_и_защита.md` — идея, сложность и пояснение значимых строк каждого решения.
