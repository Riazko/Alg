# Задача 6. Вычисление полинома

**Ограничения:** 1 секунда, 16 Мб.

## 1. Условие

Дан полином:

`P(x) = a_N * x^N + a_(N-1) * x^(N-1) + ... + a_1 * x + a_0`.

Необходимо вычислить его значение по модулю MOD для M заданных значений x.

Ограничения:
- 2 ≤ N ≤ 100000;
- 1 ≤ M ≤ 10000;
- 10 ≤ MOD ≤ 10^9;
- 0 ≤ a_i ≤ 10^9;
- 0 ≤ x_i ≤ 10^9.

## 2. Идея решения

Для вычисления значения полинома в одной точке можно использовать схему Горнера.

Вместо непосредственного вычисления степеней x последовательно пересчитываем значение:

`result = 0`

Для каждого коэффициента от старшего к младшему:

`result = (result * x + coefficient) % MOD`

Например, для полинома:

`P(x) = 2*x^2 + 3*x + 4`

вычисления будут следующими:

1. `result = 2`
2. `result = (2*x + 3) % MOD`
3. `result = (result*x + 4) % MOD`

Так мы избегаем вычисления больших степеней.

## 3. Сложность

Для одного значения x требуется O(N) операций.

Для M значений общая сложность составляет O(N*M).

Дополнительная память — O(N + M), если сохранить коэффициенты и аргументы.

**Важное замечание:** при максимальных ограничениях получается до 10^9 итераций. Поэтому обычная схема Горнера не гарантирует прохождение ограничения в 1 секунду. Это базовый корректный способ вычисления, но не полноценное решение для максимальных тестов. Для ускорения требуется алгоритм многоточечной оценки полинома. Также нельзя без дополнительного обоснования использовать преобразование Фурье по модулю: MOD не обязательно является подходящим простым числом.

## 4. Листинг программы

```python
import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))

    n, m, mod = data[0], data[1], data[2]

    coefficients = data[3:n + 4]
    arguments = data[n + 4:n + 4 + m]

    answers = []

    for x in arguments:
        result = 0

        for a in coefficients:
            result = (result * x + a) % mod

        answers.append(str(result))

    sys.stdout.write("\n".join(answers))


if __name__ == "__main__":
    main()
```

# Задача 9. Вырубка деревьев

**Ограничения:** 1 секунда, 16 Мб.

## 1. Условие

В ряд растёт n деревьев. После вырубки должно остаться m деревьев, расположенных на одинаковом расстоянии друг от друга.

Нужно определить количество способов вырубки.

Ограничения: 0 ≤ n, m ≤ 1000.

## 2. Идея решения

Если осталось:
- 0 деревьев, существует один способ;
- 1 дерево, существует n способов;
- больше деревьев, чем было изначально, способов нет.

Рассмотрим случай, когда m ≥ 2.

Пусть d — расстояние между соседними оставшимися деревьями, измеренное в исходных промежутках.

Тогда расстояние между первым и последним оставшимся деревом равно:

`(m - 1) * d`.

Оно не может превышать `n - 1`, поэтому:

`d ≤ (n - 1) // (m - 1)`.

Обозначим:

`D = (n - 1) // (m - 1)`.

При фиксированном d существует:

`n - (m - 1) * d`

способов выбрать положение первого дерева.

Следовательно, ответ равен сумме:

`answer = sum(n - (m - 1) * d)` для d от 1 до D.

Используем формулу суммы арифметической прогрессии:

`answer = D*n - (m - 1)*D*(D + 1)//2`.

Таким образом, решение выполняется за постоянное время.

## 3. Сложность

- Время: O(1).
- Дополнительная память: O(1).

## 4. Листинг программы

```python
def main():
    n, m = map(int, input().split())

    if m == 0:
        print(1)
    elif m == 1:
        print(n)
    elif m > n:
        print(0)
    else:
        d = (n - 1) // (m - 1)

        answer = (
            d * n
            - (m - 1) * d * (d + 1) // 2
        )

        print(answer)


if __name__ == "__main__":
    main()
```

# Задача 17. Охрана

**Ограничения:** 1 секунда, 16 Мб.

## 1. Условие

Сутки разделены на 10000 промежутков времени. Каждый охранник дежурит с момента A до момента B.

Если охранник приходит в момент 5 и уходит в момент 8, он охраняет промежутки 6, 7 и 8.

Нужно проверить два условия:

1. Объект охраняется в каждый промежуток времени.
2. Удаление любого одного охранника приводит к появлению неохраняемого промежутка.

Для каждого теста необходимо вывести `Accepted` или `Wrong Answer`.

## 2. Идея решения

Используем массив разностей.

Создадим массив `diff` длиной 10002.

Для каждого охранника с интервалом A, B увеличим количество охранников на промежутках A+1 ... B:

- `diff[A + 1] += 1`;
- `diff[B + 1] -= 1`.

После вычисления префиксных сумм получим количество охранников на каждом промежутке.

### Проверка первого условия

Для каждого промежутка от 1 до 10000 количество охранников должно быть больше нуля.

Если хотя бы на одном промежутке оно равно нулю, объект не охраняется постоянно.

### Проверка второго условия

Удаление любого охранника должно приводить к появлению неохраняемого промежутка.

Это означает, что у каждого охранника должен существовать хотя бы один промежуток, который охраняет только он.

Такие промежутки характеризуются условием:

`coverage[t] == 1`.

Чтобы быстро проверять наличие таких промежутков внутри интервала охранника, построим ещё один префиксный массив — `unique_prefix`.

Тогда количество промежутков, охраняемых только одним человеком, внутри интервала A+1 ... B равно:

`unique_prefix[B] - unique_prefix[A]`.

Если результат равен нулю, данный охранник не имеет собственного промежутка. Значит, его удаление не нарушит охрану.

## 3. Сложность

Пусть N — количество охранников.

- Построение массива разностей: O(N).
- Вычисление покрытия: O(10000).
- Проверка уникальных промежутков: O(N).

Итого: O(N + 10000) времени и O(10000) дополнительной памяти.

## 4. Листинг программы

```python
import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    pos = 0

    k = data[pos]
    pos += 1

    results = []

    for _ in range(k):
        n = data[pos]
        pos += 1

        guards = []
        diff = [0] * 10002

        for _ in range(n):
            a = data[pos]
            b = data[pos + 1]
            pos += 2

            guards.append((a, b))

            diff[a + 1] += 1
            diff[b + 1] -= 1

        coverage = [0] * 10001
        current = 0
        all_covered = True

        for t in range(1, 10001):
            current += diff[t]
            coverage[t] = current

            if current == 0:
                all_covered = False

        if not all_covered:
            results.append("Wrong Answer")
            continue

        unique_prefix = [0] * 10001

        for t in range(1, 10001):
            unique_prefix[t] = (
                unique_prefix[t - 1]
                + (1 if coverage[t] == 1 else 0)
            )

        valid = True

        for a, b in guards:
            unique_count = (
                unique_prefix[b] - unique_prefix[a]
            )

            if unique_count == 0:
                valid = False
                break

        results.append(
            "Accepted" if valid else "Wrong Answer"
        )

    sys.stdout.write("\n".join(results))


if __name__ == "__main__":
    main()
```

# Задача 18. Аттракцион

**Ограничения:** 1 секунда, 16 Мб.

## 1. Условие

Кресла расположены в N рядах по M кресел.

Начальный номер кресла в i-м ряду и j-й колонке:

`(i - 1) * M + j`.

Аттракцион выполняет перестановки двух рядов или двух колонок.

После завершения работы необходимо вернуть кресла в исходное положение, выполнив не более 1000 операций.

## 2. Идея решения

Поскольку аттракцион меняет местами только целые ряды и колонки, исходное положение каждого кресла можно восстановить по его номеру.

Для удобства будем использовать индексацию с нуля.

Если номер кресла равен v, то его исходные координаты:

`original_row = (v - 1) // M`

`original_col = (v - 1) % M`

### Восстановление рядов

Первый элемент каждой текущей строки позволяет определить, какой исходный ряд находится на этой позиции.

Сохраним эту информацию в массиве `row_map`.

Затем будем последовательно ставить на место нужный ряд:

1. Рассмотрим позицию i.
2. Найдём строку j, в которой находится исходный ряд i.
3. Если i и j различаются, поменяем эти строки местами.
4. Обновим массив `row_map`.

### Восстановление колонок

Аналогично используем первую строку таблицы.

По номеру кресла определим исходную колонку каждой текущей колонки.

После этого восстановим порядок колонок такими же обменами.

Максимальное количество операций:

`(N - 1) + (M - 1) = N + M - 2`.

При N и M не более 250 это не превышает 498 операций, что укладывается в ограничение 1000.

## 3. Сложность

- Чтение таблицы: O(N*M).
- Восстановление рядов: O(N*M).
- Восстановление колонок: O(N*M).
- Дополнительная память: O(N*M) для таблицы и O(N + M) для массивов перестановок.

## 4. Листинг программы

```python
import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))

    n, m = data[0], data[1]

    a = []
    pos = 2

    for i in range(n):
        a.append(data[pos:pos + m])
        pos += m

    operations = []

    # Определяем исходные номера рядов.
    row_map = [(a[i][0] - 1) // m for i in range(n)]

    # Восстанавливаем ряды.
    for i in range(n):
        j = row_map.index(i, i)

        if i != j:
            a[i], a[j] = a[j], a[i]
            row_map[i], row_map[j] = row_map[j], row_map[i]

            operations.append(("R", i + 1, j + 1))

    # Определяем исходные номера колонок.
    col_map = [(a[0][j] - 1) % m for j in range(m)]

    # Восстанавливаем колонки.
    for i in range(m):
        j = col_map.index(i, i)

        if i != j:
            for row in a:
                row[i], row[j] = row[j], row[i]

            col_map[i], col_map[j] = col_map[j], col_map[i]

            operations.append(("C", i + 1, j + 1))

    output = [str(len(operations))]

    for operation in operations:
        output.append(
            f"{operation[0]} {operation[1]} {operation[2]}"
        )

    sys.stdout.write("\n".join(output))


if __name__ == "__main__":
    main()
```

# Задача 19. Дек

**Ограничения:** 1 секунда, 64 Мб.

## 1. Условие

Необходимо реализовать дек с ограничением на максимальное количество элементов.

Поддерживаются команды:

- `push_back x` — добавить элемент в конец;
- `push_front x` — добавить элемент в начало;
- `pop_back` — удалить и вывести последний элемент;
- `pop_front` — удалить и вывести первый элемент.

При переполнении или попытке извлечения из пустого дека необходимо вывести `error`.

Связный список использовать нельзя.

## 2. Идея решения

Используем циклический буфер — массив фиксированного размера.

Храним три значения:

- `head` — индекс первого элемента;
- `size` — количество элементов;
- `capacity` — максимальный размер дека.

Индекс последнего элемента вычисляется так:

`tail = (head + size - 1) % capacity`.

При добавлении в начало сдвигаем `head` назад:

`head = (head - 1) % capacity`.

При добавлении в конец записываем элемент по индексу:

`(head + size) % capacity`.

При удалении первого элемента увеличиваем `head`, а при удалении последнего просто уменьшаем `size`.

Все операции выполняются за O(1).

## 3. Сложность

- Каждая операция: O(1).
- Память: O(capacity).
- Общая обработка n команд: O(n).

## 4. Листинг программы

```python
import sys

def main():
    input = sys.stdin.readline

    n = int(input())
    capacity = int(input())

    buffer = [0] * capacity
    head = 0
    size = 0

    output = []

    for _ in range(n):
        command = input().split()

        operation = command[0]

        if operation == "push_front":
            value = int(command[1])

            if size == capacity:
                output.append("error")
            else:
                head = (head - 1) % capacity
                buffer[head] = value
                size += 1

        elif operation == "push_back":
            value = int(command[1])

            if size == capacity:
                output.append("error")
            else:
                index = (head + size) % capacity
                buffer[index] = value
                size += 1

        elif operation == "pop_front":
            if size == 0:
                output.append("error")
            else:
                output.append(str(buffer[head]))
                head = (head + 1) % capacity
                size -= 1

        elif operation == "pop_back":
            if size == 0:
                output.append("error")
            else:
                index = (head + size - 1) % capacity
                output.append(str(buffer[index]))
                size -= 1

    sys.stdout.write("\n".join(output))


if __name__ == "__main__":
    main()
```

# Задача 21. Пирамидальная сортировка

**Ограничения:** 1,5 секунды, 256 Мб.

## 1. Условие

Необходимо реализовать сортировку кучей (heapsort), не используя готовые реализации куч.

Каждый участник имеет:
- логин;
- количество решённых задач P;
- штраф F.

Порядок сортировки:

1. Больше решённых задач — выше место.
2. При равном количестве задач меньший штраф — выше место.
3. При равных результатах и штрафах раньше идёт логин, расположенный раньше в лексикографическом порядке.

## 2. Идея решения

Реализуем пирамидальную сортировку.

Для этого создадим функцию `is_worse(a, b)`, которая проверяет, является ли участник a хуже участника b.

Участник считается хуже, если:
- решил меньше задач;
- при равном количестве задач получил больший штраф;
- при равных результатах имеет логин, который позже в алфавитном порядке.

Построим max-heap, в корне которого находится худший участник.

Затем будем менять корень с последним элементом неотсортированной части массива и восстанавливать свойство кучи.

После завершения худшие участники окажутся в конце массива, а лучшие — в начале.

## 3. Сложность

- Построение кучи: O(N).
- Сортировка: O(N log N).
- Дополнительная память сортировки: O(1).
- Память для хранения участников: O(N).

Итоговая временная сложность: O(N log N).

## 4. Листинг программы

```python
import sys

def is_worse(a, b):
    if a[0] != b[0]:
        return a[0] < b[0]

    if a[1] != b[1]:
        return a[1] > b[1]

    return a[2] > b[2]


def sift_down(heap, size, i):
    while True:
        largest = i
        left = 2 * i + 1
        right = 2 * i + 2

        if left < size and is_worse(
            heap[left], heap[largest]
        ):
            largest = left

        if right < size and is_worse(
            heap[right], heap[largest]
        ):
            largest = right

        if largest == i:
            break

        heap[i], heap[largest] = (
            heap[largest], heap[i]
        )

        i = largest


def heap_sort(heap):
    n = len(heap)

    # Построение max-heap.
    for i in range(n // 2 - 1, -1, -1):
        sift_down(heap, n, i)

    # Извлечение элементов из кучи.
    for end in range(n - 1, 0, -1):
        heap[0], heap[end] = heap[end], heap[0]
        sift_down(heap, end, 0)


def main():
    input = sys.stdin.buffer.readline

    n = int(input())
    participants = []

    for _ in range(n):
        login, solved, penalty = input().split()

        participants.append((
            int(solved),
            int(penalty),
            login
        ))

    heap_sort(participants)

    output = [
        participant[2].decode()
        for participant in participants
    ]

    sys.stdout.write("\n".join(output))


if __name__ == "__main__":
    main()
```
